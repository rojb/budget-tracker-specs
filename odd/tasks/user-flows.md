# User flows page and missing screens

## Objective
Add a `Flujos` page to the design that groups the screens into named user flows. Also design the screens the PRD requires but that do not exist yet.

## Problem / why
The 18 screens sit in a grid with no narrative. Several PRD requirements have no screen, including two that the teacher will check: FR-12 (month settle) and FR-13 (edit/delete with full recalculation).

## Constraints

- New screens:
  - 390x844, v3 design system (tokens in PRD-ux-spec.md §7), UI copy in Spanish.
  - Reuse the node names and structures of the existing patterns (StatusBar, BottomNav, FieldRow, TxRow, EnvelopeRow, SaveBar, PrimaryButton, TextField…) so that the build turns them into component instances.
- OpenPencil 0.8.4 gotchas are listed in odd/tasks/component-library.md; the key ones are z-order and path stretching.
- The Flujos page is generated by the build. For each flow it shows a title, the FRs it covers and a short description, then the step screens in order, with arrows and numbered captions.
